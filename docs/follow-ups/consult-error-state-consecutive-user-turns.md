# 호출 실패 후 새 문장을 보내면 사용자 발화가 연속으로 쌓인다

**Symptom**: 오류 상태에서 "다시 시도"를 누르지 않고 새 문장을 보내면 대화 기록이 `[user, user]`로 이어져 Gemini에 연속된 사용자 줄이 전달된다.

**Observed evidence**: 코드 리뷰에서 `features/consult/consult-panel.tsx`의 입력창이 오류 상태에서도 활성화되고 `send`가 기존 `messages`에 이어 붙이는 것을 확인했다. 실제 재현은 하지 않았다.

**Suspected cause**: 오류 상태에서 입력을 막거나 마지막 사용자 발화를 교체하는 처리가 없다.

**What was tried**: 수정하지 않았다. "다시 시도"는 대화를 유지한 채 같은 요청을 다시 보내므로 인수 기준 8은 만족한다.

**Proposed next step**: 오류 상태일 때 `send`가 마지막 미응답 사용자 발화를 새 입력으로 교체하게 하거나, 입력창을 비활성화하고 "다시 시도"만 허용한다.
