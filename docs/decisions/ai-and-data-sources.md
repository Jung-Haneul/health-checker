# AI와 외부 데이터 출처

## Decisions

- 증상 해석, 좁히는 질문, 의심 원인과 대처법 생성은 Gemini API 무료 티어(서버에서 호출)가 맡습니다.
- 약 정보(제품명, 효능, 사용법, 주의사항, 부작용)는 식약처 e약은요 공공 API의 응답만 근거로 보여줍니다. LLM이 약 이름이나 효능을 직접 지어서 보여주지 않습니다.
- 무료 티어에 보낸 입력은 구글의 서비스 개선에 쓰일 수 있으므로, 증상을 입력하는 화면에는 이 사실과 "개인정보를 적지 마세요"라는 고지를 항상 보여줍니다.
- API 키는 서버 환경 변수로만 다루고 브라우저에 노출하지 않습니다.

## Boundaries

- 학습용 템플릿 범위의 결정입니다. 실제 서비스로 운영한다면 유료 티어 전환과 개인정보 처리 방침을 다시 판단해야 합니다.
- 공공 API에 해당 약이 없으면 약 안내를 비우고 "약국에서 상담하세요"로 대신하며, LLM이 약을 대신 추천하지 않습니다.

## Why

증상을 자유롭게 섞어 말하는 입력과 답에 따라 바뀌는 질문은 고정 규칙표로 만들 수 없어 LLM이 필요합니다. 무료 공공 API 중 한국어로 증상에서 원인을 추리해 주는 것은 찾지 못했습니다. 약 정보는 틀리면 해로우므로 공식 데이터에 묶습니다. 무료 티어의 데이터 사용 조건은 [Gemini 가격 문서](https://ai.google.dev/gemini-api/docs/pricing)에 명시되어 있어, 숨기지 않고 고지하는 쪽을 택했습니다.

## Reconsider when

- 개인정보 보호가 필요한 실제 사용자에게 서비스를 공개할 때
- 무료 티어 한도나 데이터 사용 조건이 바뀔 때

## Still-rejected alternatives

- 규칙 기반으로 소수 증상만 다루는 방식 — 제품 정의의 "누구나, 어떤 증상이든"과 맞지 않습니다. LLM을 쓸 수 없을 때만 다시 검토합니다.
- 유료 티어 사용 — 학습용 템플릿에 비용이 생깁니다. 실제 운영 시 다시 검토합니다.
- LLM이 약 정보까지 직접 생성 — 잘못된 약·효능 안내의 위험이 큽니다.
